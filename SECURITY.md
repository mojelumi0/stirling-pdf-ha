# Security policy

## Supported versions

Security fixes are applied to the latest published prerelease or stable release.
Older alpha builds may be asked to update before a report is investigated.

## Reporting a vulnerability

Do not publish API keys, private URLs, document contents, filenames, paths, or
unredacted Home Assistant logs in a public issue.

If GitHub shows **Security → Report a vulnerability** for this repository, use
that private form. Otherwise, open a minimal public issue asking the maintainer
for a private contact method without including sensitive or exploit details.

For vulnerabilities in Stirling PDF itself, follow the security policy in the
[official Stirling PDF repository](https://github.com/Stirling-Tools/Stirling-PDF/security/policy).

Please include the affected integration version, Home Assistant version,
Stirling PDF version, authentication mode, and the smallest safe reproduction
description possible.
